## 2. Утверждения, принятые в этой сессии

- **Светлая тема по умолчанию — «Стекло»** (пастель + стеклянные поверхности).
- **Пастель — отдельная шкала токенов**, а не разбавленный основной цвет:
  `--pastel-mint/lilac/peach/sky/lemon`.
- **Текст — чернильный** `#1b1f3b` с четырьмя уровнями прозрачности
  (100 / 72 / 68 / 52 %), без чистого чёрного.
- **Стекло**: `backdrop-filter: blur(18px) saturate(150%)`, волосяная граница,
  мягкая тень, запасной непрозрачный вариант через `@supports`.
- **Кнопки — пилюли**, без чёрных заливок: primary — фиолетовый `#5b4be0`,
  вторичные — контурные, опасные — контурные красные.
- **Шрифты**: Golos Text для текста, Manrope для заголовков и чисел;
  оба лежат локально в `backend/static/fonts/`, OFL.
- **Одна кривая анимации** `cubic-bezier(.4, 0, .2, 1)`, 140/220 мс.
- **Три темы**: «Стекло», «Графит» (прежний тёплый вариант с медью),
  «Ночь» (тёмный графит со сталью). Выбор запоминается в localStorage;
  `?theme=glass|graphite|night` — предпросмотр без сохранения.
- **Из student.itmo.ru взяты принципы, а не копирование**: пастельные шкалы,
  контурные кнопки, SVG/градиентный меш на фоне, уровни прозрачности текста,
  единая кривая анимации. Их `backdrop-filter` в исходниках мёртвый —
  у нас он рабочий, с fallback.
- **Контраст** текстовых пар пересчитан до AA (пастель на стекле, статусы,
  приглушённый текст).

## 5. Технические заметки

- Токены и компоненты — `backend/static/css/main.css`; блоки тем:
  `:root` (Стекло), `[data-theme="graphite"]`, `[data-theme="night"]`,
  плюс `@media (prefers-color-scheme: dark)` для системной темы.
- Переключатель и хранение — `backend/static/js/theme.js`
  (ключ `labbooking-theme`; старые `light`/`dark` нормализуются в
  `graphite`/`night`).
- Шрифты: `backend/static/fonts/` (`golos-*`, `manrope-*`, `OFL.txt`,
  `OFL-MANROPE.txt`).
- Версии статики: `main.css?v=20261120e`, `theme.js?v=20261120c`,
  `dashboard.js?v=20261120c`.
- Запуск: `pg-start.bat` (порт 5433), затем `python manage.py runserver`.
  Быстрый предпросмотр тем: `/login/?theme=glass|graphite|night`.
- Ничего не закоммичено: все изменения в рабочем дереве.
